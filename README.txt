MARY'S BIRTHDAY WEBSITE

Upload index.html, style.css, and script.js to the same folder in your GitHub repository.

Upload your own media files into that same folder:
- Photo1.jpg
- Photo2.jpg
- Photo3.jpg
- Birthday.mp3

The filenames must match exactly, including uppercase letters. If the song has a different extension, update the audio src in index.html.

Enable GitHub Pages in repository Settings > Pages if it is not enabled already.
